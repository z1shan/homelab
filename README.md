# Homelab

A personal homelab focused on Linux servers, self-hosted services, networking, security, automation, and infrastructure experimentation.

## Overview

This repository documents my homelab environment and the infrastructure I build, configure, break, troubleshoot, and improve.

The goal is to maintain a practical environment for learning system administration, networking, cybersecurity, virtualization, containerization, and self-hosting.

## Infrastructure

The homelab includes experiments and configurations involving:

- Linux servers
- Virtual machines
- Containers
- Docker
- Networking
- DNS
- DHCP
- Firewalls
- Reverse proxies
- Storage
- Monitoring
- Self-hosted applications
- Security tooling
- Automation
